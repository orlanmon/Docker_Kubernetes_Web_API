ASP.NET CORE MVC RESTful Web API which has Docker support and which is then published to 
Azure Kubernetes Service (AKS) cluster via Azure DevOps CI/CD Pipeline.

Steps 
#1 Added Docker support to ASP.NET CORE MVC RESTful Web API

#2 Docker Image Published to Docker Desktop, and then a Docker Container created from that Docker Image.

#3 In Azure created Azure Container Registry, and then created Azure Kubernetes Service (AKS) cluster 

#3 ASP.NET CORE MVC RESTful Web API with Docker support in GitHub published to Azure Kubernetes Service (AKS) cluster with 
an Azure DevOps CI/CD Pipeline generated by customizing a Docker Image to Azure Kubernetes Service (AKS) cluster pipeline.
